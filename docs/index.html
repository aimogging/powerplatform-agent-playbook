Power Platform agent playbook

Build and test canvas apps and cloud flows with an AI agent; hand production nothing but packages a person imports.

1. Check the tools (no tenant needed)

From the repository root:

python tools/run-self-tests.py
python example/build.py --check

2. Point it at a dev tenant

cp config/environment.example.json config/environment.json

Fill in the tenant id, environment id, site URL and your address. The file is git-ignored; token caches live in ~/.pp-playbook/.

cd tools
python -m devtenant login sharepoint
python -m devtenant whoami
cd ..

3. The loop

StepWhatTier
Authorflow definition.json, canvas Src/*.pa.yaml, list schema JSON
Checkflowcheck.py, canvas-lint.py0 offline
Dev testdeploy.py (provision, flows, app, publish, runtime gate), drive flows and the app1 dev tenant
Packagebuild-flow-package.py, msapp-tool.py stamp
Handoffnumbered import steps + a test checklist with expected results
Productiona person imports (Update, pick connections, Save as > Replace existing, publish) and reports2 target

Rule: always report the tier each artifact reached; never present tier 0 or 1 as production-proven.

4. Try the example end to end

python example/build.py --base "C:\path\to\downloaded shell.msapp"
python tools/deploy.py --manifest example/deploy.manifest.json --plan-only

The full walkthrough (manual import path and automated dev path) is in example/README.md.
